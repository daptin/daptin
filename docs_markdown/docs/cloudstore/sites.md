Sites
==

Sites are publicly accessible servers hosting static content over HTTP and HTTPS.

FTP can also be enabled to expose a path on a cloud store as an FTP site. FTP uses the site's existing owner and related-usergroup permissions: `Peek` controls discovery and entry, `Read` controls listing and downloads, `Create` controls new uploads and directories, `Update` controls overwrite and rename operations, and `Delete` controls removal. Restart Daptin after changing FTP enablement, site permissions, or site-usergroup relationships.
