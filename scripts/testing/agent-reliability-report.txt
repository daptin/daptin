DAPTIN RELIABILITY QUALIFICATION

NOT QUALIFIED: repeated cluster restart can partition Olric or terminate a node during startup

The 50-cycle test did not complete. The longest attempt completed three cycles before membership failed to converge. The final attempt completed two cycles; cycle two split the cache cluster, and a node exited during cycle three startup. No manual restarts were used to make the test appear successful.

Fixed during testing: concurrent schema upload lost updates; batch creation with omitted optional metadata.

Passed: rollback, keyed imports and partial-schema merges on SQLite/PostgreSQL/MariaDB; concurrent compatible tables/columns/relations/actions and rejection of conflicting columns; active agent/action/batch drain with one external effect each; forced inference cancellation and continuation; permission and ownership regressions; ordinary Go suite, agent/LLM race detector, affected-package vet.

Measured 289,095 operations with 0 errors, including 850 completed agent runs. Read measurements below are the repeat with other server suites finished. Providers were deterministic local HTTP servers.
